# 🎈 Interactive Birthday Surprise App

A vibrant, non-romantic interactive birthday surprise web application built with Python and Streamlit.

## ✨ Features
- **Interactive Candle Blowing:** Interactive ASCII cake animation with blow-out candle logic.
- **Surprise Messages:** Custom styled dynamic greeting card with personalized messages.
- **Pastel Palette & High Contrast UI:** Tailored CSS styling with bold typography for high readability.

## 🚀 Live Demo
Check out the live app here: [Gauri's Birthday App](https://gauribday-iq8cyj82daqtrbt2nrtytw.streamlit.app/)

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Deployment:** Streamlit Community Cloud
